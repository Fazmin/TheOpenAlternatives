# Open-Source Alternatives to Popular Paid Productivity Software

A curated guide to well-regarded, actively maintained open-source replacements for the paid tools most used at work, in education, and for office and project management. Most can be self-hosted. Some also offer an optional paid cloud plan.

## Office Suites
| Paid Software | Open-Source Alternative | Short Description |
|---|---|---|
| Microsoft Office | [LibreOffice](https://www.libreoffice.org/) | Full desktop suite with Writer, Calc, Impress, Draw, and Base. It has strong support for MS Office formats. |
| Microsoft 365 / Google Workspace (online editing) | [ONLYOFFICE Docs](https://github.com/ONLYOFFICE/DocumentServer) | Self-hosted collaborative editor for documents, spreadsheets, and slides with high DOCX/XLSX/PPTX fidelity. |
| Google Docs | [Collabora Online](https://www.collaboraonline.com/) | LibreOffice-based online office suite. It integrates with Nextcloud and other platforms. |

## Project Management
| Paid Software | Open-Source Alternative | Short Description |
|---|---|---|
| Jira | [Plane](https://github.com/makeplane/plane) | Modern tracker for issues, sprints (cycles), and roadmaps. |
| Microsoft Project | [OpenProject](https://www.openproject.org/) | Classic and agile project management with Gantt charts, time tracking, and budgets. |
| Trello | [Wekan](https://github.com/wekan/wekan) | Self-hosted Kanban boards modeled on Trello. |
| Trello / Asana | [Focalboard](https://github.com/mattermost-community/focalboard) | Kanban, table, and calendar boards for projects and tasks. |
| Asana / Monday.com | [Taiga](https://taiga.io/) | Agile project management with Scrum and Kanban. |
| Jira (dev teams) | [Redmine](https://www.redmine.org/) | Mature, flexible issue tracker with wikis, Gantt charts, and plugins. |

| Roam Research / Obsidian Sync | [Logseq](https://github.com/logseq/logseq) | Privacy-first outliner with bidirectional links. |
